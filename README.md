# Choice — SillyTavern 行动选项插件

在 SillyTavern 角色扮演对话中，额外调用一次 API **异步生成一组「行动选项」**：玩家点选后按所选方式进入输入框或直接发送，不占用楼层，也不打断主回复的节奏。基于 Vue 3 + Pinia + Zod + Vite。

## 功能特性

### 核心

- **行动选项生成**：使用独立的 API 配置异步生成，与酒馆主对话的 API 互不影响。支持四种点击行为——发送 / 覆盖输入框 / 尾附在末尾 / 插入光标处；数量支持固定值或区间（如 `3-6`，每次随机），可调每条字数与人称视角；生成后自动剔除与上一轮重复的选项并补齐。
- **条目池**：条目库（所有条目的总仓库，按分组管理）+ 配置（决定本次生成从哪些条目抽取）两层结构。配置可绑定到角色或聊天，优先级为聊天 > 角色 > 默认；条目库条目支持类型、内容、规则、固定与权重，配置层可对每个条目再覆盖启用 / 固定 / 权重；条目库可按当前角色 AI 批量生成，条目池与配置支持 JSON 导入导出（合并 / 替换）。
- **提示词双轨**：`本扩展提示词`（默认）用模块列表组装——system / user / assistant 模块可拖拽排序、启停、复制、编辑，支持润色专用模块；`酒馆预设` 完全使用酒馆当前对话补全（CC）预设，自读预设 + 自组装，不劫持宿主生成管线，并支持采样跟随（含 max_tokens 下限，避免正文预设截断选项）、提示词后处理透传、脚本层三档（默认关）与按预设名隔离的条目覆盖（禁用 / 内容替换）。
- **知识边界**（默认开）：把「{{user}} 此刻知道什么」做成聊天级账本——独立分析逐条判定 **已知 / 存疑 / 未知** 与获取来源（目击 / 听闻 / 阅读 / 推断 / 未获取），生成选项时按当前场景筛选注入（锁定 / 未知 / 存疑优先）。账本支持增量补丁、相似度归并、手动整理、锁定 / 退役 / 恢复、导入导出与容量治理；自动分析默认每累计 10 轮新消息重跑一次，编辑 / 删除 / 滑动 / 载入立即重跑；可选把分析与选项生成合并为一次请求（先更新边界再写候选）。

### 上下文与内容

- **世界书注入**：复用酒馆原生世界书构建，逐书四态循环 **全关 / 跟随酒馆 / 全启用 / 自定义**（自定义可逐条勾选）；支持全局排除列表与来源徽章（全局 / 角色 / 聊天 / 数据库）；每轮只构建一次（选项生成与知识分析共用，EJS 副作用不双跑）。
- **聊天记录过滤**：新手可用的**标签提取**（只填标签名，如「正文」，发送时只保留 AI 输出里的 `<正文>…</正文>` 段落，用户输入原样保留）；进阶的**正则库**按分组集中管理，需被三个分区引用才生效——全局正则区（始终生效）、预设正则区（随预设切换）、角色卡正则区（随角色卡切换）；支持从酒馆全局 / 预设 / 角色卡批量导入。执行顺序恒定为**先提取、后过滤**，页顶开关控制是否先走酒馆正则。
- **输入润色**（默认开）：发送前把玩家输入改写成多个润色版本供挑选，选中的才真正发出；版本数支持固定值或区间。

### 界面与交互

- **悬浮球与选项面板**：悬浮球显示空闲 / 生成中 / 禁用状态（知识分析时另有独立绿色光点），单击呼出选项或设置，右键 / 长按快捷菜单，拖拽吸附边缘，环形 / 紧凑两种样式；聊天内选项面板可停靠「聊天内」或「输入框上方」，支持面板状态锁定与「点击聊天正文收起」（默认关）；酒馆输入框左侧魔棒菜单入口可显隐。
- **外观**：主题支持自动检测酒馆亮暗 / 完全跟随酒馆配色 / 强制暗色 / 强制亮色，另有 4 套独立预设主题（暮紫 / 樱粉 / 青瓷 / 蜜杏）；字体默认跟随设备，可手动固定档位；选项 HUD（分级色条、悬停增强、滑入动画与已选打勾，默认开）。
- **功能课堂**：分章节引导（快速上手 / 条目池 / 生成与点击行为 / 提示词 / 世界书 / 过滤 / 外观），各页与弹窗另有 ❓ 页内指引。

### 进阶（默认关）

- **骰子判定**：AI 在选项标题标注需求值（`[标题|档位|70]`），点选时掷 D100 判定大成功 / 成功 / 失败 / 大失败并演绎程度。支持 DND / COC 双模式（高低骰方向）、属性驱动需求值、NdM 骰式表达式、就地重掷；判定结果以隐形 HTML 注释随消息持久化（聊天界面不可见、正文 AI 可读），主面板与悬浮球同步显示需求值徽标与判定 chip。
- **统计**：按条目池配置维度统计生成 / 选择计数、7 / 30 天趋势、条目命中率与随机期望对比、样本充足度；只计选项视图（润色不计入），支持导出 JSON 与清空。
- **记忆桥接**（可选）：提示词页的「柏宝书」开关把外部记忆系统的剧情摘要作为记忆上下文注入（摘要层与正文零重复）；「数据库」开关让外部结构化记忆书的目标世界书参与选项 / 润色生成。桥接不可用时零变化。
- **调试**：查看上次生成上下文（提示词链路、知识边界注入、输出上限、后处理、脚本层、世界书构建次数与缓存命中）、数据版本统计与恢复出厂设置。

## 安装

```bash
# 克隆到 SillyTavern 插件目录
cd SillyTavern/public/scripts/extensions/third-party
git clone https://github.com/Junwu-Git/choice.git
```

在酒馆扩展管理面板中启用 Choice 插件，刷新页面即可。

## 快速入门

1. **配置 API**：打开设置 → API，添加 API 配置（地址 + 密钥 + 模型），点「保存」
2. **确认条目**：全新安装已内置条目库（8 组 68 条）与默认配置，开箱即用；想自定义时在「条目池」新建或 AI 生成条目，再创建配置并绑定到角色 / 聊天
3. **生成选项**：AI 每次回复完成后会自动生成一组（默认开启），也可点选项面板头部的 ✨ 手动生成
4. **点选使用**：点击选项按当前点击行为填入或发送；面板头部可随时切换点击行为

## 开发

```bash
pnpm install
pnpm build      # 一次性打包
pnpm watch      # 开发监听模式（需手动刷新浏览器）
pnpm test       # vitest 纯函数单测（选项解析 / 骰子 / 条目池 / 预设 / 知识边界等）
pnpm typecheck  # vue-tsc 类型检查
pnpm lint       # ESLint
pnpm i18n:check # 文案键缺失 / 孤儿检查
pnpm format     # Prettier
```
