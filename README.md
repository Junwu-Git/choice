# Choice — SillyTavern 行动选项插件

为 SillyTavern 角色扮演对话异步生成"行动选项"，供玩家点选后填入/发送。基于 Vue 3 + Pinia + Zod + Vite。

## 功能特性

- **行动选项生成**：单独调用 API 异步生成选项，不影响主回复生成。支持发送 / 覆盖输入框 / 插入光标处 / 尾附四种行为模式
- **条目池管理**：总条目库 + 配置架构，配置可绑定到角色或聊天，优先级为聊天 > 角色 > 默认
- **提示词模块化**：system/user/assistant 模块可拖拽排序、复制、编辑，支持润色专用模块
- **悬浮球**：状态指示器（Idle/Generating/Disabled），长按快捷菜单，拖拽吸附边缘
- **输入润色**：AI 将用户输入改写为多个润色版本供选择，支持固定数量或随机区间
- **骰子判定**（默认关）：AI 在选项标题标注需求值（`[标题|档位|70]`），点选时掷 D100 判定大成功/成功/失败/大失败并演绎程度。支持 DND/COC 双模式、属性驱动需求值、NdM 骰式表达式、就地重掷；判定结果随消息持久化，主回复 AI 可感知判定上下文
- **卡牌收藏**（默认关）：判定管线的叠加层——武器/法术/祝福/试炼四槽装备 + 星级预算，行动币经济（按判定结局收支 → 开包 3 选 1），角色主题卡池随剧情分批 AI 生成，永久收藏 + 触发磨损/行动币修复
- **行动统计与建议**（默认关）：按配置维度统计条目参与/命中，采纳感知随机基线，生成条目权重调整建议并可一键应用/撤销；可选 AI 归因修正与建议理由
- **世界书注入**：复用 ST 原生 `getWorldInfoPrompt`，支持排除/启用特定书籍
- **聊天记录过滤**：标签/正则按规则分组过滤聊天历史
- **主题跟随**：自动检测 ST 亮/暗主题，或完全跟随 ST 配色（含对比度守卫）
- **导入导出**：条目池 + 配置一键导出 JSON，支持合并/替换两种导入模式
- **柏宝书记忆源**：可选启用柏宝书摘要+状态作为提示词模块

## 安装

```bash
# 克隆到 SillyTavern 插件目录
cd SillyTavern/public/scripts/extensions/third-party
git clone https://github.com/Junwu-Git/choice.git
```

在酒馆扩展管理面板中启用 Choice 插件，刷新页面即可。

## 快速入门

1. **配置 API**：打开设置 → API 标签，添加 API 配置（地址 + 密钥 + 模型），点击保存
2. **创建条目**：打开设置 → 条目池 → 条目库，添加行动选项条目（或导入他人分享的条目库）
3. **绑定配置**：创建配置，勾选条目，绑定到当前角色或聊天
4. **生成选项**：在消息下方点击「生成」按钮，AI 生成选项后点击即可填入/发送

## 开发

```bash
pnpm install
pnpm build      # 一次性打包
pnpm watch      # 开发监听模式（需手动刷新浏览器）
pnpm test       # vitest 单元测试（抽取算法/骰子判定/选项解析/归因/卡牌约束）
pnpm typecheck  # vue-tsc 类型检查
pnpm lint       # ESLint
```
