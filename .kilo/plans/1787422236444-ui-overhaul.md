# Choice 扩展 UI 全面美化方案

## 设计方向

暗色主题 + 蓝色主色调（#4a90d9），注入现代感：
- **深度感**：玻璃拟态（`backdrop-filter: blur()`）+ 多层阴影
- **流动感**：渐变背景、微妙光晕动画、hover 上浮
- **呼吸感**：交互元素 scale 反馈、过渡动画（150-300ms ease-out）
- **精致感**：更细的边框（1px rgba）、统一圆角、图标点缀
- **一致感**：CSS 变量统一所有颜色/间距/圆角/阴影

## 丝滑拖动方案

用 `useDraggable` 的 `isDragging` 状态控制 CSS `transition`：

- 拖拽中：`transition: none`，用 `transform: translate()` 跟手（GPU 加速）
- 松手后：`transition: transform 0.4s cubic-bezier(0.34, 1.56, 0.64, 1)` — 弹簧回弹到边界

关键改动：不再用 `useDraggable` 返回的 `style`（`left: Xpx; top: Ypx`），改用 `x`/`y` refs 自建 `transform: translate(${x}px, ${y}px)`。还需要显式 `position: fixed`。

适用组件：`FloatingBubble`、`FloatingSettings`（两个都用到 `useDraggable`）。

## 约束

- 仅改动 scoped `<style>` 和 `theme.css`/`global.css`，不改模板 `<script>` 逻辑（除 Bubble 移除 isMobile 和 Settings 加图标）
