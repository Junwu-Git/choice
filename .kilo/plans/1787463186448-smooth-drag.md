# 悬浮球与设置面板拖动丝滑化

## 问题
`FloatingBubble.vue` 和 `FloatingSettings.vue` 使用 `useDraggable` 但只解构 `{ isDragging }`，`posX`/`posY` 仅于 `onEnd` 更新。拖动过程中元素不跟随指针，松手后通过 CSS transition 动画跳到目标位置。

## 修复

### 1. FloatingBubble.vue
- 解构 `useDraggable` 返回的 `x`、`y` ref
- 拖动中实时绑定 `x`/`y` 到 `transform`
- 添加 `isDragging` 时 `will-change: transform` 提升到 GPU 合成层
- `onEnd` 中仅做边界限制 + 持久化到 `useStorage`

### 2. FloatingSettings.vue
- 同上，解构 `x`、`y` 实时绑定
- 添加 `will-change: transform`

### 3. 可选优化
- 将 `transform: translate(Xpx, Ypx)` 改为 `translate3d(Xpx, Ypx, 0)` 触发硬件加速
- 移除松手时的弹跳动画（`cubic-bezier(0.34, 1.56, 0.64, 1)` 改为线性），因为元素已跟随指针，不需要"飞"过去

## 影响范围
- `src/components/FloatingBubble.vue` — 模板 + script
- `src/components/FloatingSettings.vue` — 模板 + script

## 验证
1. `pnpm build` 通过
2. 浏览器刷新后拖拽悬浮球，确认元素跟随鼠标实时移动
3. 拖拽设置面板标题栏，确认面板跟随鼠标实时移动
4. 拖拽后松手，确认位置持久化（刷新后位置保留）
5. 点击悬浮球（非拖拽）仍能打开设置面板
